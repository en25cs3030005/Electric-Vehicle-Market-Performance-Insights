# Electric Vehicle Market Performance & Insights

## 📌 About the Project
This project explores the Electric Vehicle (EV) market using Tableau Desktop. It analyzes sales across manufacturers, vehicle categories, model years, countries, and battery technologies through interactive visualizations.

## 🎯 Project Objectives
- Analyze EV sales across manufacturers and countries.
- Compare sales across vehicle categories and battery technologies.
- Explore sales trends across model years.
- Present insights through a Tableau dashboard and story.

## 🛠️ Tools & Technologies
- **Tableau Desktop** – Data visualization and dashboards.
- **CSV** – Dataset format.
- **Python (Flask)** – Website development.
- **HTML/CSS** – Website design.
- **GitHub** – Project documentation and file management.
- **Render** – Website deployment.

## 📂 Dataset Description
The project includes two datasets:
- `ev_market_train.csv`
- `ev_market_test.csv`

The datasets contain EV sales, manufacturers, categories, model years, battery specifications, prices, ratings, countries, and sustainability information.

The Tableau analysis uses the training dataset. Both datasets are kept separate.

## 📊 Data Visualizations
Seven visualizations were created:

1. Sales by Manufacturer – Bar Chart
2. Sales by Category – Donut Chart
3. EV Sales Trend – Line Chart
4. Sales by Country – Country Plot
5. Annual Sales by Battery Technology – Bar Chart
6. Price vs. Annual Sales – Scatter Plot
7. EV Sales by Manufacturer – Treemap
